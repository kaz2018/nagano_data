# Agent Rules

## 開発プロセスと役割分担
- 計画の策定：計画は fable5 もしくは sonnet5 が行い、コードの実装は antigravity cli で行います。

## デプロイとCI/CD
- コード管理：コードは GitHub にプッシュします。
- デプロイ自動化：Cloudflare で自動連携し、リポジトリの変更を監視して自動的にデプロイを行います。

## 外部データ取得とサンドボックス環境
- エージェントの実行環境（antigravity CLI等）はデフォルトでネットワークが遮断されたサンドボックス下で動作します。
- Python スクリプト等から直接外部URLへアクセス（urllibやrequests等）すると `socket.gaierror` や `URLError` となり失敗します。
- 外部データを取得する際は、スクリプト実行前に独立したダウンロードコマンド（`curl` など）で生データ（`*_raw.csv` 等）を取得し、加工スクリプトはローカルファイルを読み込んで処理が完結するように設計してください。
