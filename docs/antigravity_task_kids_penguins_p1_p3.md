# 実装依頼：ペンギン研究所コース 第1章（kids/penguins/ P1〜P3）

## 概要

こどもコースに **2つめの探検「🐧 ペンギン研究所」** を新設し、その第1章（レッスン3本）を作る。
長野県の人口データ（人のデータ）に対して、ペンギン編は **「1ぴきずつ測った生き物のデータ」** を扱う。
「1行＝1個体」「列＝測った項目」という表の基本と、平均・ちらばりを学ぶ。

- **コース名**: ペンギン研究所
- **コースのサブタイトル**: 南極のデータで、もっと深く
- **配置**: `kids/penguins/` 配下（こどもコースの一部。独立コースではない）
- **コース共通の body 背景**: `bg-sky-50`
- **登場人物**: でい太・ポン太・ものしり仙人（既存キャラのみ。**新キャラは作らない**）
- **使用データ**: Palmer Penguins（palmerpenguins, CC0）

今回のスコープは **P1〜P3 とコース一覧ページ、データ生成スクリプトまで**。
P4以降（散布図・島・オスメス・欠損・シンプソンのパラドックス）は次フェーズなので**作らない**。

### `penguins_ja.csv`（344行）

列は**この順・この名前で固定**：

```
しゅるい,島,くちばしの長さ(mm),くちばしの深さ(mm),ひれの長さ(mm),体重(g),せいべつ,年
```

- 行の順番は原典のまま（並べ替えない）
- **欠損はそのまま空欄で出力する**（後のレッスン7の教材になる。0や「不明」で埋めない）
- 体重・ひれの長さは整数、くちばしは小数1桁

### `lesson02_species_mass.csv`（3行）

```
しゅるい,ひき数,へいきん体重(g),へいきんひれの長さ(mm)
アデリーペンギン,152,3701,190.0
ヒゲペンギン,68,3733,195.8
ジェンツーペンギン,124,5076,217.2
```

- `ひき数` は**行数**（アデリー152・ヒゲ68・ジェンツー124、合計344）
- `へいきん体重(g)` は**欠損を除いた平均**を四捨五入した整数（アデリー151匹・ジェンツー123匹から計算される）
- 行の順番は アデリー → ヒゲ → ジェンツー（体重の昇順にならないよう注意。この順で固定）

### `lesson03_mass.csv`（342行）

```
しゅるい,体重(g)
```

- 体重が欠損している2行（アデリー1・ジェンツー1）を**除外**した342行
- 行の順番は原典のまま

生成後に以下を検査し、1つでも合わなければエラーで落とす：

### 可視化：サマリー＋ならびかえできる表（344行）

1. **サマリーカード**（4枚・grid）：`ぜんぶで 344ひき` / `しゅるい 3` / `島 3` / `年 2007〜2009`
   数字はCSVから**JSで数えて表示する**（ハードコードしない）。
   さらにその下に、しゅるいごとのひき数を小さいバッジで出す（アデリーペンギン 152 / ジェンツーペンギン 124 / ヒゲペンギン 68）。これもJSで集計する。
2. **表**：`initKidsSortableTable` を使う。344行あるので、
   - `<div class="max-h-[28rem] overflow-y-auto rounded-xl border border-cyan-100">` でスクロール領域に入れる
   - `<thead>` に `sticky top-0 bg-white z-10` を付け、スクロールしても見出しが残るようにする
   - 表の上に「列の名前をタップすると、ならびかえられるよ」と案内を出す

```js
initKidsSortableTable({
  csvUrl: '../data/penguins_ja.csv',
  headId: 'peng1-table-head',
  bodyId: 'peng1-table-body',
  columns: [
    { key: 'no', label: 'No', type: 'number', align: 'right' },
    { key: 'species', label: 'しゅるい', type: 'text', align: 'left' },
    { key: 'island', label: '島', type: 'text', align: 'left' },
    { key: 'flipper', label: 'ひれの長さ(mm)', type: 'number', align: 'right' },
    { key: 'mass', label: '体重(g)', type: 'number', align: 'right' },
    { key: 'sex', label: 'せいべつ', type: 'text', align: 'left' },
  ],
  transformRow: (row, index) => ({ /* 略：CSVの日本語ヘッダーから詰め替える */ }),
  theme: {
    rowBorderClass: 'border-cyan-50',
    rowHoverClass: 'hover:bg-cyan-50',
    maxCellClass: 'bg-cyan-200 text-cyan-900 font-bold',
  },
});
```

**注意（重要）**：`initKidsSortableTable` は数値列の最大値セルをハイライトする実装になっている。
`no` 列は連番なのでハイライトが邪魔になる。`no` は `type: 'text'` にするか、`render` を指定して数値ハイライトが付かないようにすること。
空欄セル（体重・せいべつ）は `render` で `—`（`text-gray-300`）と表示し、**ソート時に NaN で崩れないようにする**こと。
体重が空欄の行が最大値扱いにならないことも確認する。
